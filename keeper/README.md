# settlement keeper
`node keeper/settle.mjs --dry` prints what would be bought. Without `--dry` and with `TREASURY_PK` set it swaps ETH -> USDG -> stock token on Uniswap v3 (Robinhood Chain) with the claimant as recipient, then marks the claim settled with the tx hash. `--loop` polls every minute. Treasury: a dedicated Stockback wallet generated for this project only (address in .env as TREASURY_ADDRESS); fund it with ETH on Robinhood Chain to enable payouts. Env: TREASURY_PK, SUPABASE_URL, SUPABASE_ANON_KEY, STOCKBACK_API_SECRET, optional RPC_URL, MAX_ETH_PER_CLAIM (default 0.02).
